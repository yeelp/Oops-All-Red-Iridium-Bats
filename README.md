# About
Transforms all Iridium Bats to their scarier red counterparts!

## What's a Red Iridium Bat?
[Red Iridium Bats are a vanilla feature](https://stardewvalleywiki.com/Bats#Trivia)! They replace Iridium Bats in the Skull Cavern at floor 880 and beyond!
